[English below](#english)

Cursor / Claude / Codex の「あとどれだけ使えるか」を、メニューバーとデスクトップのウィジェットに出しておく macOS アプリです。
今回から、自分でビルドしなくても DMG から入れられるようになりました。

SHA-256: `b7ab9aae4522e17829ca181dbcd1b0611580c1fb32c629a207aebb604597ecd0`

## インストール

1. DMG を開き、**AI使用量** を **Applications** フォルダへドラッグします。
2. アプリケーションフォルダから **AI使用量** を起動します。Dock には出ず、メニューバーに表示されます。
3. デスクトップを右クリック →「ウィジェットを編集」→ **AI使用量**（英語環境では **AI Usage**）を選んで配置します。
4. 置いたウィジェットを右クリック →「ウィジェットを編集」で、表示するサービスを選びます。
5. 常用するなら、システム設定 →「一般」→「ログイン項目」に登録してください。ウィジェットが更新されるのはアプリが起動しているあいだだけです。

**動作条件:** macOS 14 以降。見たいサービスのアプリ（Cursor.app / Claude Code CLI / Codex CLI）にログインしていること。

## できること

- **3 サービスの使用量を 1 か所で** — Cursor / Claude / Codex をメニューで切り替え。ウィジェットは配置ごとに別のサービスを指定できます。
- **プラン枠と従量の両方** — プラン名・リセット日・枠ごとの使用率（5時間枠・週次枠など）・オンデマンドや追加クレジットの金額。
- **API キーだけでも** — Claude / OpenAI の Admin キーがあれば、公式 Cost API で今月の API 費用を表示します。
- **ウィジェット（小・中・大）** — 右上のボタンで一時停止 / 再開と更新ができます。
- **日本語 / English** — 既定はシステム言語。メニューから切り替えられます。

## 最近の主な変更

- macOS 27.2.1 で、ウィジェットの編集画面でサービスを選んでも表示が変わらず、閉じたあと右クリックメニューが出なくなる問題を直しました（選択肢を検索つきリストに変更）
- Claude Code がトークンを更新したあと、ログインし直さなくても新しいトークンを読み直すようにしました（#19）
- レート制限（429）を受けたら自動更新の間隔を空け、ウィジェットからの更新要求が API を叩き続けないようにしました（#18）
- Claude デスクトップアプリでは CLI のトークンが更新されないことを、期限切れのメッセージで案内するようにしました（#17）
- ログイン直後やスリープ復帰後に、ウィジェットがプレースホルダのまま止まる問題を直しました（#14, #16）
- ウィジェットの背景を macOS 標準のものにしました（#15）
- Claude のクラウドセッションクレジットを表示するようにしました（#11）
- 配布に向けて hardened runtime を有効にしました

## ご注意

- **以前に自分でビルドして入れていた場合は、先にそちらを削除してください**（`~/Applications/AI使用量.app` など）。同じアプリが 2 か所にあると、ウィジェットがプレースホルダのままになることがあります。配布版は自前ビルドと App Group が異なるため、選択中のサービスや一時停止の状態は引き継がれません。
- **ローカルの資格情報を読みます。** このアプリはサンドボックスを外しており、Cursor の `state.vscdb`、Claude Code の資格情報、Codex の `auth.json` を読んで、各社の使用量エンドポイントへ送ります。Claude Code の Keychain を読むときは確認ダイアログが出ることがあります（「常に許可」を選ぶと次回から出ません）。トークンを外部へ送ることも、ログに出すこともありません。
- **非公式 API を使っています。** Cursor / Claude / Codex のプラン使用量は公式 API がないため、各サービスの非公式エンドポイントを使っています。サービス側の変更で突然取れなくなることがあります。
- 詳しい使い方とトラブルシューティングは [README](https://github.com/shigeya-t/ai-usage-widget#readme) を参照してください。

# AI Usage 1.1.0 — first downloadable build

A macOS menu bar app and widget that shows how much of your Cursor / Claude / Codex usage is left.
Starting with this release you can install it from a DMG instead of building it yourself.

## Download

| File | Notes |
| --- | --- |
| `AIUsageWidget-1.1.0.dmg` | Signed with Developer ID and notarized by Apple |

SHA-256: `b7ab9aae4522e17829ca181dbcd1b0611580c1fb32c629a207aebb604597ecd0`

## Install

1. Open the DMG and drag **AI Usage** into the **Applications** folder.
2. Launch **AI Usage** from Applications. It lives in the menu bar, not the Dock.
3. Right-click the desktop → **Edit Widgets** → choose **AI Usage** and place a widget.
4. Right-click the widget → **Edit Widget** to choose which service it shows.
5. To keep it running, add it under System Settings → General → Login Items. Widgets only update while the app is running.

**Requirements:** macOS 14 or later, and a login in the app for each service you want to see (Cursor.app / Claude Code CLI / Codex CLI).

## Features

- **Three services in one place** — switch between Cursor, Claude and Codex in the menu; each widget can show a different service.
- **Plan limits and pay-as-you-go** — plan name, reset date, per-limit usage (5-hour, weekly, …) and on-demand or extra-credit spend.
- **API keys work too** — with a Claude or OpenAI Admin key, shows this month's API cost from the official Cost API.
- **Small, medium and large widgets** — with pause/resume and refresh buttons.
- **Japanese and English** — follows the system language by default; switchable from the menu.

## Recent changes

- Fix the widget edit sheet not showing the chosen service, and the right-click menu no longer appearing after closing it, on macOS 27.2.1 (the choices are now a searchable list)
- Re-read Claude credentials after Claude Code rotates the token, so you no longer need to log in again (#19)
- Back off automatic refreshes after a rate limit (429) so widgets stop hammering the usage APIs (#18)
- The token-expired message now explains that the Claude desktop app does not renew the CLI token (#17)
- Fixed widgets staying on the placeholder after login or wake (#14, #16)
- Widgets now use the standard macOS widget background (#15)
- Show Claude cloud session credits (#11)
- Enabled the hardened runtime for distribution

## Notes

- **If you built and installed the app yourself before, delete that copy first** (e.g. `~/Applications/AI使用量.app`). Two copies of the app can leave the widget stuck on its placeholder. This build uses a different App Group from self-built copies, so the selected service and pause state are not carried over.
- **It reads local credentials.** The app runs outside the sandbox so it can read Cursor's `state.vscdb`, Claude Code's credentials and Codex's `auth.json`, and sends those tokens only to each service's usage endpoint. Reading Claude Code's Keychain item may show a confirmation dialog (choose "Always Allow" to stop it reappearing). Tokens are never logged or sent anywhere else.
- **It uses unofficial APIs.** There is no official API for personal plan usage, so the app calls each service's unofficial endpoint. It may break without notice if a service changes.
- See the [README](https://github.com/shigeya-t/ai-usage-widget/blob/main/README.en.md) for usage details and troubleshooting.
