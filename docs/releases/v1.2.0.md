- **Claude の週次 Fable 枠を表示するようにしました（#22）。** 週次 Opus / 週次 Sonnet と並んで「週次 Fable」が出ます。Fable の枠がないアカウントでは出ません。

## 更新のしかた

1. メニューバーの **AI使用量** を終了します。
2. DMG を開き、**AI使用量** を **Applications** フォルダへドラッグして置き換えます。
3. アプリケーションフォルダから **AI使用量** を起動します。

配置済みのウィジェットと設定はそのまま使えます。初めて入れる場合の手順は [README](https://github.com/shigeya-t/ai-usage-widget#readme) を参照してください。

**動作条件:** macOS 14 以降。見たいサービスのアプリ（Cursor.app / Claude Code CLI / Codex CLI）にログインしていること。

## ご注意

- **以前に自分でビルドして入れていた場合は、先にそちらを削除してください**（`~/Applications/AI使用量.app` など）。同じアプリが 2 か所にあると、ウィジェットがプレースホルダのままになることがあります。
- **ローカルの資格情報を読みます。** このアプリはサンドボックスを外しており、Cursor の `state.vscdb`、Claude Code の資格情報、Codex の `auth.json` を読んで、各社の使用量エンドポイントへ送ります。トークンをそれ以外へ送ることも、ログに出すこともありません。
- **非公式 API を使っています。** Cursor / Claude / Codex のプラン使用量は公式 API がないため、各サービスの非公式エンドポイントを使っています。サービス側の変更で突然取れなくなることがあります。

# AI Usage 1.2.0 — Claude weekly Fable limit

A macOS menu bar app and widget that shows how much of your Cursor / Claude / Codex usage is left.
This release adds the Claude weekly Fable limit.

## Download

| File | Notes |
| --- | --- |
| `AIUsageWidget-1.2.0.dmg` | Signed with Developer ID and notarized by Apple |

SHA-256: `41ac68fe10bc9bc4d66405cff8616b3c31a07f88bc4d1ae9b73b36c503292293`

## Changes

- **Show the Claude weekly Fable limit (#22).** "Weekly Fable" appears next to Weekly Opus / Weekly Sonnet. It is not shown for accounts without a Fable limit.

## Updating

1. Quit **AI Usage** from the menu bar.
2. Open the DMG and drag **AI Usage** into the **Applications** folder, replacing the old copy.
3. Launch **AI Usage** from Applications.

Your widgets and settings are kept. For a first install, see the [README](https://github.com/shigeya-t/ai-usage-widget/blob/main/README.en.md).

**Requirements:** macOS 14 or later, and a login in the app for each service you want to see (Cursor.app / Claude Code CLI / Codex CLI).

## Notes

- **If you built and installed the app yourself before, delete that copy first** (e.g. `~/Applications/AI使用量.app`). Two copies of the app can leave the widget stuck on its placeholder.
- **It reads local credentials.** The app runs outside the sandbox so it can read Cursor's `state.vscdb`, Claude Code's credentials and Codex's `auth.json`, and sends those tokens only to each service's usage endpoint. Tokens are never logged or sent anywhere else.
- **It uses unofficial APIs.** There is no official API for personal plan usage, so the app calls each service's unofficial endpoint. It may break without notice if a service changes.
